# Turtle Race Game 🐢🏁

A fun, interactive turtle racing game built in Python using the built-in `turtle` and `random` modules. Place your bets and watch the turtles dash across the screen!

## Features
* **Dynamic Setup:** Automatically generates 6 uniquely colored turtles lined up at the starting gate.
* **User Betting:** Prompts you to input a color bet before the race begins.
* **Randomized Movement:** Turtles move forward by random step intervals (`0` to `10` pixels) each turn to keep the race unpredictable.
* **Win/Loss Detection:** Automatically detects when the first turtle crosses the finish line and announces whether your bet was correct.
